Claude Code Multi-Model Agent Runtime (Windows x64)
===========================================================

ENGLISH VERSION
------------------------------------------------

1. Installation

Running `ClaudeCodeBridge-<version>-Setup.exe` directly is recommended.

1. Accept the Windows Administrator permissions prompt.
2. Follow the setup wizard to complete installation.
3. Gemini setup is optional and unchecked by default; no API key is required if not using Gemini.
4. If Gemini is desired, check "Configure Google Gemini" and enter your API Key. The installer automatically detects and prefills the Windows system proxy if present (editable; clear to use direct connection).
5. After installation or upgrade completes, restart any running Claude Code sessions. A session started before the authentication upgrade may otherwise receive 401 Unauthorized.

Upgrades snapshot the existing Windows service configuration and running state. If a later installation step fails, the installer restores that snapshot; a service created by the failed attempt is removed. GUI Setup also uses the pre-UAC user's profile, Pictures, Desktop, and SID for Claude configuration, generated images, and shortcuts. If Setup itself was launched from an already elevated process, Windows cannot provide that original-user token.

The ZIP package is portable. To use it, extract the entire archive first, then double-click `Install.cmd`.

Service listens on:
http://127.0.0.1:18787

Windows Service Name:
ClaudeCodeBridge

2. Model Switcher GUI

The installer creates a Start Menu shortcut and optionally a Desktop shortcut.
The GUI allows inspecting bridge status, reloading profiles, and switching active models live.
Gemini proxy settings can be inspected, edited, tested, and applied instantly from the GUI without reinstalling or restarting the service (clearing proxy and saving selects direct connection).
The installer registers claude-computer-host.exe as the local gemini-computer stdio MCP server. Claude Code starts and manages it automatically; Model Center does not need to be open. Browser launches an isolated localhost-only 1440x900 browser. Desktop asks the signed-in user to select a window only when computer_start runs. High-risk batches show a one-shot Host confirmation dialog. See COMPUTER_USE.md.

The GUI reads bridge-owned provider profiles from:
%USERPROFILE%\.claude\bridge-providers\*.json
Copy a template from the installed examples\providers directory, remove
".example" from its filename, and fill in the provider's official OpenAI-compatible
base_url, api_key, and model values. Then click Reload in the GUI.
See PROVIDER_CONFIG.md for the full field reference and migration guide.
Legacy settings - *.json profiles remain available during gradual migration;
equivalent native profiles take precedence.

3. File Locations

Program executable:
C:\Program Files\ClaudeCodeBridge

API Key, state, and logs:
C:\ProgramData\ClaudeCodeBridge

Claude Code configuration:
%USERPROFILE%\.claude

Bridge Provider configuration:
%USERPROFILE%\.claude\bridge-providers

The installer creates a timestamped backup before modifying `settings.json`.
It also generates a random local bridge token at:
C:\ProgramData\ClaudeCodeBridge\local-auth-token
Claude Code, the Model Center, shutdown scripts, and the Gemini image MCP use it automatically. A valid existing token is reused on upgrade; it is never used as an upstream provider API key.
New local-token, Gemini-key, and install-metadata files receive restrictive ACLs before secret bytes are written, then are atomically published.

For source development, `scripts\start-bridge.ps1` reuses the installed token, an explicitly configured token, or an existing development token. If none exists, it securely creates `target\local-auth-token`; bundled stop and test scripts resolve the same token automatically. A direct executable launch must set `GEMINI_BRIDGE_LOCAL_TOKEN` or `GEMINI_BRIDGE_LOCAL_TOKEN_FILE`.

4. Updating API Key

Open "Configure or Update Gemini API Key" from the Start Menu and enter the new key.
Portable ZIP users can also double-click `Update-API-Key.cmd`.

5. Uninstallation

Uninstall via Windows "Installed apps" or the Start Menu shortcut.
Portable ZIP users can double-click `Uninstall.cmd`.

API keys, logs, and Claude settings are preserved by default to prevent accidental data loss.
The uninstaller uses the protected pre-install snapshot to restore Claude environment variables. Values changed by the user after installation are not overwritten.
To remove `C:\ProgramData\ClaudeCodeBridge`, delete it manually after confirming it is no longer needed.

6. Important Notes

1. Binaries are not digitally signed; Windows SmartScreen may show an "Unknown publisher" warning.
2. Connections are accepted only from local 127.0.0.1; ports are not exposed to the local network.
3. Except for `/health` and `/v1/models`, Messages, Responses, Token Count, MCP, and management APIs require the local bridge token.
4. API keys and the local bridge token are kept separately in access-controlled files, not in the service registry.
5. Streaming requests have no ten-minute whole-response deadline, but a stream with no bytes for two minutes is terminated; non-streaming requests retain the ten-minute limit.
6. Vision Proxy fails explicitly instead of silently dropping untranslatable media and processes at most 16 historical media messages per request.
7. Do not distribute configuration files containing API keys or the local bridge token.
8. Gemini PDF requests automatically omit only native Code Execution because Google rejects that combination; Search, URL Context, local tools, and non-PDF Code Execution remain available.
9. Gemini Interactions implicit-cache hits are managed by Google and are not guaranteed per request. A zero cached-token count does not by itself indicate a bridge failure.
10. v0.8.0 adapts the native Computer Use capability newly provided by Gemini 3.8 Flash. Gemini plans actions, Claude Code manages the local stdio MCP Host, and the signed-in-user Host executes them without a second model or Model Center window. Browser navigation is limited to localhost/127.0.0.1/[::1], sessions are capped at 50 steps or 15 minutes, and computer_cancel closes the active lifecycle exactly once.

中文版本 (CHINESE VERSION)
================================================

一、安装

推荐直接运行 ClaudeCodeBridge-版本-Setup.exe。

1. 同意 Windows 管理员权限提示。
2. 按安装向导完成安装。
3. Gemini 是可选项，默认不勾选；不使用 Gemini 时无需输入 API Key。
4. 如需 Gemini，勾选“配置 Google Gemini”，再输入 API Key。安装器会自动检测并预填 Windows 系统代理，用户可以修改；清空代理表示直连。
5. 安装或升级成功后，重新启动正在运行的 Claude Code 会话。在启用本地鉴权之前启动的旧会话否则可能收到 401 Unauthorized。

升级前会保存现有 Windows 服务配置与运行状态；后续步骤若失败，安装器会恢复该快照，本轮失败安装新建的服务则会被删除。GUI 安装还会使用 UAC 前用户的 profile、图片、桌面与 SID 来定位 Claude 配置、生成图片和快捷方式。若 Setup 本身从已经提升权限的进程启动，Windows 无法再提供该原始用户令牌。

ZIP 是便携发布包，需要使用时请先完整解压，再双击 Install.cmd。

服务会监听：
http://127.0.0.1:18787

Windows 服务名：
ClaudeCodeBridge

二、模型切换 GUI

安装程序会创建开始菜单快捷方式，也可以按需创建桌面快捷方式。
GUI 可以查看桥接状态、重新加载配置并实时切换模型。
Gemini 代理可在 GUI 中随时检测、修改、测试并立即生效，无需重新安装或重启服务；清空后保存表示直连。
安装器会把 claude-computer-host.exe 注册为本地 gemini-computer stdio MCP Server，由 Claude Code 自动拉起和管理，无需打开模型中心。Browser 启动仅允许 localhost 的隔离 1440×900 浏览器；Desktop 只在 computer_start 执行时要求真实用户选窗。高风险批次由 Host 弹出一次性安全确认。详见 COMPUTER_USE.md。

不使用 Gemini 时，GUI 会读取已有的
%USERPROFILE%\.claude\settings - *.json
供应商配置。若尚无配置，服务仍可正常安装，添加配置后重新加载即可。

三、文件位置

程序：
C:\Program Files\ClaudeCodeBridge

API Key、状态和日志：
C:\ProgramData\ClaudeCodeBridge

Claude Code 配置：
%USERPROFILE%\.claude

安装程序修改 settings.json 前会创建带时间戳的备份。
安装程序还会生成随机本地桥接令牌，保存在：
C:\ProgramData\ClaudeCodeBridge\local-auth-token
Claude Code、模型中心、停止脚本和 Gemini 生图 MCP 会自动使用该令牌，无需手工复制。
升级时会复用已有的有效令牌；该令牌绝不会被用作上游 Provider API Key。
新建本地令牌、Gemini Key 与安装元数据文件时，会先设置受限 ACL，再写入密钥字节，最后原子发布。

源码开发时，`scripts\start-bridge.ps1` 会复用安装令牌、显式配置的令牌或已有开发令牌；都不存在时，会安全创建 `target\local-auth-token`。随附的停止和测试脚本会自动解析同一令牌。若直接启动可执行文件，则必须设置 `GEMINI_BRIDGE_LOCAL_TOKEN` 或 `GEMINI_BRIDGE_LOCAL_TOKEN_FILE`。

四、更新 API Key

从开始菜单打开“配置或更新 Gemini API Key”，输入新 Key。
便携包用户也可以双击 Update-API-Key.cmd。

五、卸载

从 Windows“已安装的应用”或开始菜单卸载。
便携包用户可以双击 Uninstall.cmd。

默认保留 API Key、日志和 Claude 配置，避免误删个人数据。
卸载器会按受保护的安装前快照恢复 Claude 环境变量；安装后由用户自行修改过的值不会被覆盖。
如需删除 C:\ProgramData\ClaudeCodeBridge，请在确认不再需要后手工删除。

六、注意事项

1. 本软件没有商业代码签名证书，Windows 可能显示“未知发布者”。
2. 只接受来自本机 127.0.0.1 的连接，不对局域网开放端口。
3. 除 /health 和 /v1/models 外，Messages、Responses、Token Count、MCP 与管理 API 都需要本地桥接令牌。
4. API Key 与本地桥接令牌不写入服务注册表，分别存放在受访问控制保护的文件中。
5. 流式请求没有 10 分钟整流总时限，但连续两分钟无数据会终止；非流式请求仍保留 10 分钟上限。
6. Vision Proxy 遇到无法转换的媒体会明确失败，不会静默丢图；单次请求最多处理 16 条历史媒体消息。
7. 请勿将自己已经填写 API Key 的配置文件或本地桥接令牌转发给他人。
8. Gemini PDF 请求会自动只省略 Google 不接受与 PDF 同时使用的原生 Code Execution；Search、URL Context、本地工具以及非 PDF 请求的 Code Execution 仍可使用。
9. Gemini Interactions 的隐式缓存命中由 Google 管理，不保证每个请求命中；cached-token 为 0 不能单独说明桥接器故障。
10. v0.8.0 针对 Gemini 3.8 Flash 新提供的原生 Computer Use 能力完成适配：Gemini 决策，Claude Code 管理本地 stdio MCP Host，用户态 Host 执行，不调用第二个模型，也不要求打开模型中心。Browser 仅允许 localhost/127.0.0.1/[::1]，会话限制为 50 步或 15 分钟；computer_cancel 会且只会关闭一次当前生命周期。
